Zig 0.16 · WebP / JPEG · default 200 KB · up to 8 workers

Why use it

Everything you need to make photos web-ready in one shot.

🖼️

Universal input

JPEG, PNG, BMP, TGA, GIF and more. Powered by stb_image.

📐

Photo-grade resize

High-quality linear downscale to 1920px with stb_image_resize2.

⚡

WebP or JPEG

WebP by default, or progressive JPEG via libjpeg-turbo.

🧹

Metadata stripped

EXIF, GPS and IPTC removed — more bytes for pixels, less dead weight.

🧵

Smart multi-thread

Configurable worker pool (1–8) to process entire folders in parallel.

🎯

Precise target size

Adaptive quality until under the limit. If still over, writes anyway with a warning.

Install & Build

# dependencies (macOS)
brew install zig webp jpeg-turbo

# or Ubuntu/Debian
sudo apt install zig libwebp-dev libturbojpeg0-dev

# build
git clone https://github.com/ricbuz94/shrinkpic
cd shrinkpic
zig build -Doptimize=ReleaseFast

# binary → zig-out/bin/shrinkpic

Usage

shrinkpic <input_dir> [output_dir] [--size=200kb] [--jpeg] [--workers=4]
--size=150KB

Max target size (MB/KB). Default 200kb.

--jpeg

Force progressive JPEG instead of WebP.

--workers=8

Parallel threads (1–8). Default 4.
